# Detecção de Anomalias e Fraudes em Cartão de Crédito

## Descrição do Projeto
Projeto de Ciência de Dados para identificação de transações fraudulentas utilizando algoritmos de Machine Learning no dataset Credit Card Fraud Detection.

## Resultados e Conclusões
O modelo supervisionado **Random Forest** apresentou o melhor desempenho geral no combate a fraude financeira, alcançando uma precisão de **96%** e um recall de **74%** na detecção da classe minoritária (fraudes).

O modelo não supervisionado **Isolation Forest** serviu para identificar anomalias sem  o uso de dados rotulados prévios, sendo uma boa alternativa para cenários onde novos tipos de fraudes desconhecidas surgem constantemente.
